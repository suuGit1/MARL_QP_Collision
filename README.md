# MARL_QP_Collision

Independent research repository for communication-limited hierarchical safe multi-agent power-grid control.

## Research line

The project starts from the MIT/RTE e-Energy 2026 communication-limited multi-agent congestion-management framework and will progressively study:

1. exact reproduction of the MIT/RTE baseline;
2. safety-contract conditioned multi-agent control;
3. graph-constrained MARL;
4. operational/constraint collision modeling;
5. event-triggered QP safety projection;
6. hierarchical safety guarantees under limited communication.

## Current stage

**P0 — MIT/RTE original-paper reproduction**

No new MARL, collision, or QP-safety contribution is introduced in P0. The objective is to establish a clean, auditable baseline first.

Upstream: https://github.com/MOSSLab-MIT/comm-limited-congestion-mgmt
